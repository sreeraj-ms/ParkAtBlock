APPLICATION PURPOSE
-------------------

This is a parking management application that displays the real-time availability of parking slots.

ESP32 devices are connected to HC-SR04 ultrasonic sensors.

Each ESP32 represents a parking slot.

The ESP32 sends measured distance to the ASP.NET Core API.

The backend determines:

distance < 50 cm
    => occupied

distance >= 50 cm
    => available

The backend then sends parking state changes to connected clients through SignalR.

The frontend must display these changes in real time without requiring page refreshes.


IMPORTANT ARCHITECTURE
----------------------

The frontend must use two communication mechanisms:

1. REST API
   Used for:
   - Initial loading of parking state
   - Getting individual slot details
   - Future management operations

2. SignalR
   Used for:
   - Real-time parking status changes
   - Receiving ParkingSlotUpdated events

On application startup:

1. Connect to the REST API.
2. Call GET /api/parking/slots.
3. Populate the initial parking state.
4. Establish a SignalR connection to /hubs/parking.
5. Subscribe to ParkingSlotUpdated.
6. Update the UI immediately when an event arrives.

Do not continuously poll the API for parking status.

SignalR should be the primary mechanism for real-time updates.
